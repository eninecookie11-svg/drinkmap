# 제품 이미지 기준

- PNG, 600×600px, 투명 배경.
- 제품 실루엣의 높이 386px. 가로세로 비율을 유지하고 가로 중앙에 배치.
- 위쪽 126px, 아래쪽 약 88px 여백. 펩시 라임 사진과 같은 높이 기준.
- 그림자·다른 물체·배경 제거 잔여물은 제외.
- 기준 파일: `public/assets/coka-zero-normalized.png`.
- 코카제로 원본 `coka-zero.png`는 보관. 보정본은 내장 이미지 편집 도구로 배경 잔여물을 제거한 뒤 크기를 정규화했다. 포장 문구를 검증하는 자료로 사용하지 않는다.
- 편집 지시: 캔 디자인과 비율을 유지하고 왼쪽 잔여물을 제거, 투명 배경에서 제품 높이를 펩시와 일치시킨다.
