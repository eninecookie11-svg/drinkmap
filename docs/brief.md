# 제로픽(ZeroPick) 제작 브리프

## 한 문장
제로음료를 즐겨 마시는 사람이 제품을 구매하기 전, 대체감미료·카페인·영양성분·가격을 한곳에서 확인하고 자신에게 맞는 음료를 발견하는 제로음료 도감.

## 쓰는 사람과 그 순간
20대 제로음료 애호가가 편의점이나 온라인 쇼핑몰에서 음료를 고르는 순간. (가정)
휴대폰으로 제품을 검색하다가 어떤 감미료가 들어 있는지, 카페인이 있는지 궁금해진다.
제조사마다 정보가 흩어져 있고, 제로슈거라고 해도 성분이 달라 비교하기 어렵다.
제로픽에서 검색 한 번으로 궁금증을 해결하고 새로운 음료도 발견한다.

## 이것 하나는 끝내주게
제품명을 검색하면 10초 안에 제품 사진, 감미료 종류, 카페인 유무, 영양성분, 가격을 확인한다.
가장 중요한 화면은 제품 상세정보이며, 원재료명 속 감미료를 알아보기 쉽게 구분한다.
확인된 정보와 확인되지 않은 정보를 명확히 구별해 신뢰할 수 있게 한다.

## 들어갈 것
### 꼭 있어야 하는 것
- 사용자가 제품명·브랜드로 검색하고 음료 사진을 보며 제품을 탐색할 수 있다.
- 사용자가 제품별 감미료 종류·카페인 유무 및 함량·영양성분·원재료명·알레르기 정보를 확인할 수 있다.
- 사용자가 감미료 종류, 카페인 유무, 브랜드, 음료 종류로 제품을 필터링하고 정렬할 수 있다.
- 사용자가 제품의 정가·할인가·판매처·가격 확인일을 구분해 보고 용량당 가격을 비교할 수 있다.
- 사용자가 두 제품 이상을 선택해 성분과 가격의 차이를 비교할 수 있다. (가정)
### 여유가 되면
- 감미료별 설명 사전, 비슷한 음료 추천, 최근 본 제품, 사용자 직접 가격 입력 및 가성비 계산.
### 넣지 않는 것
- 필수 회원가입: 검색해서 들어온 방문자의 이용을 방해한다.
- 근거 없는 건강 점수·안전성 순위: 성분만으로 건강 영향을 단정할 수 없다.
- 검증되지 않은 자동 수집 가격·가짜 후기: 정보 신뢰도를 떨어뜨린다.

- 검색 안내: "코카콜라 제로, 펩시 제로, 수크랄로스..."

### 데이터의 깊이와 운영 원칙
- 초기 목표는 국내 판매 제품 30종 이상. 위 14종을 시작으로 공식 자료를 확인해 확장하고, 확인된 정보만 공개한다.
- 제품별 브랜드·정식 제품명·맛·용량·제품 이미지·원재료명·감미료·카페인 유무/함량·열량·당류·탄수화물·나트륨·알레르기·출처·확인일을 기록한다.
- 가격은 판매처·포장 수량·정가·할인가·배송비·확인일을 구분하고, 개당 가격과 100ml당 가격을 계산한다. 현재가를 확인하지 못하면 숫자를 만들어내지 않는다.
- 출처: 제조사 공식몰(mall.lottechilsung.co.kr), 코카콜라 공식 안내(ccbhelp.zendesk.com), 한국소비자원 제로음료 비교정보(2024.08), 제품 포장 표시.
- 감미료 사전: 아스파탐 / 수크랄로스 / 아세설팜칼륨 / 알룰로스 / 스테비올배당체 / 에리스리톨. 정의·특징·제품 내 사용 여부를 출처와 함께 설명한다. (확인 필요)
- 정보가 없으면 "미확인", 가격을 갱신하지 못하면 "최근 가격 확인 불가"로 표시한다. 미확인을 무함유로 해석하지 않는다.
- 제품 이미지 사용 권한을 확인하고, 제품별 배합·표시 변경 가능성을 반영한다. 출시 제품과 판매 중단 제품을 구분한다.

## 느낌
- 프라이스웨건의 직관적인 가격 판단 경험을 참고하되, 제로픽은 제품을 수집하고 둘러보는 음료 도감의 즐거움을 중심에 둔다.
- 진열대에서 다양한 음료를 구경하듯 제품 패키지가 눈에 들어오고, 마음에 드는 음료를 눌러 성분을 알아보는 경험.
- 피할 인상: 숫자만 빽빽한 엑셀 표, 쇼핑몰 광고 전단지, 근거 없이 건강을 평가하는 사이트, 어디서나 본 듯한 AI 템플릿.
- 쓰고 난 뒤 남길 인상: "몰랐던 제로음료도 발견했고, 이제 뭘 마시는지 알고 고를 수 있겠다."

## 조건
- 형태와 기술: 로그인 없이 이용하는 검색 중심 반응형 웹사이트. 기술 선택은 제작 AI가 판단한다. (가정)
- 주로 쓰는 기기: 휴대폰, 데스크톱에서도 정상 이용. (가정)
- 배포·비용: 초기 무료 운영, Cloudflare Pages 배포, 유료 서버·API 의존 최소화.
- 수익 방식: Google AdSense 광고 공간을 마련하되 검색·성분 확인을 방해하지 않는다. 승인 전에는 실제 광고가 표시되지 않아도 된다.
- 만드는 사람: 비전공자, Claude Code 또는 VS Code + Gemini CLI가 구현하며 제품 데이터를 쉽게 추가·수정할 수 있어야 한다. (가정)

## 잘 됐는지 보는 기준
- 첫 화면을 보고 3초 안에 제로음료 성분 검색 사이트임을 알 수 있다.
- 제품명을 검색하면 10초 안에 감미료·카페인·영양정보를 찾을 수 있다.
- 사진을 보며 제품을 탐색하고, 감미료·카페인 조건으로 원하는 음료를 좁힐 수 있다.
- 제품마다 확인된 데이터의 출처와 확인일이 있고, 없는 정보는 만들어내지 않는다.
- 휴대폰에서도 탐색·비교가 편하고 광고가 핵심 정보 확인을 방해하지 않는다.
