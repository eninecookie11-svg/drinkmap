# 이미지 권리 기록

현재 `public/assets/*.svg`는 이 프로젝트에서 직접 작성한 제품 구분용 벡터 일러스트입니다.
브랜드 공식 사진이나 패키지 디자인의 정확한 복제가 아니며 실제 사진이라고 표시하지 않습니다.
상표와 제품명의 권리는 각 권리자에게 있습니다.

현재 공식 제품 사진의 상업적 재사용 허락은 확보하지 않았습니다.
사진을 교체할 때 아래 정보를 제품 id별로 기록하세요.

| 제품 id | 파일 경로 | 제공자·원본 URL | 상업 이용·변형 허용 근거 | 확인일 | 필수 출처 표기 |
|---|---|---|---|---|---|

제조사 홈페이지에 공개됐다는 이유만으로 재사용 허락이 있다고 보지 않습니다.
직접 촬영한 사진도 배경·인물 등 별도 권리를 확인하세요.
